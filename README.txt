SAMI BANK — SEPARATED SOURCE FILES

Files:
- index.html  : HTML structure and page content
- styles.css  : all CSS extracted from the original inline style blocks
- app.js      : JavaScript extracted from the original inline script

How to run:
1. Keep all three files in the same folder.
2. Open index.html in a browser, or open the folder in VS Code and use Live Server.
3. Do not rename styles.css or app.js unless you also update their references in index.html.

The original layout, styles, and JavaScript logic have been retained during separation.
This remains an educational prototype; it does not connect to real banking/payment systems.
